# GearForge 3D ⚙️

**GearForge 3D** (چرخ‌دنده‌ساز دقیق) یک وب‌اپلیکیشن مهندسی و پیشرفته برای طراحی، شبیه‌سازی کینماتیک سه‌بعدی و خروجی استاندارد انواع چرخ‌دنده‌ها می‌باشد.

---

## 🌟 ویژگی‌های کلیدی (Key Features)

1. **انواع چرخ‌دنده‌ها:**
   - چرخ‌دنده ساده (Spur Gear)
   - چرخ‌دنده مارپیچ (Helical Gear)
   - چرخ‌دنده شانه‌ای و پینیون (Rack & Pinion)
   - چرخ‌دنده مخروطی (Bevel Gear)

2. **شبیه‌سازی قطار چرخ‌دنده‌ها و دورسنج (Kinematics & RPM Multi-Gear Assembly):**
   - قابلیت تعریف ۲ یا چند چرخ‌دنده درگیر
   - تعیین چرخ‌دنده محرک (Primary Driver) و چرخ‌دنده‌های متحرک (Driven)
   - تنظیم دور چرخ‌دنده محرک (مثلاً ۳۰۰۰ دور در دقیقه / 3000 RPM) و محاسبه خودکار نسبت دور ($i$) و دور در دقیقه و جهت چرخش ساعتگرد/پادساعتگرد برای تمام چرخ‌دنده‌ها
   - انیمیشن فیزیکی روان و هماهنگ چرخش دندانه‌ها

3. **خروجی‌های استاندارد مهندسی CAD و پرینت ۳بعدی:**
   - **DXF (2D):** مناسب برای AutoCAD، SolidWorks، برش لیزر، پلاسما و وایرکات CNC.
   - **STEP / STP (3D):** استاندارد ISO 10303-21 برای کتیا، سالیدورکز، فیوژن ۳۶۰ و FreeCAD.
   - **STL (3D Mesh):** آماده برای اسلایسر Cura / Prusa و پرینت سه‌بعدی.
   - **ارسال مستقیم:** امکان اشتراک‌گذاری فایل از طریق Web Share API یا ایمیل برای همکار و کارگاه.

4. **محیط سه‌بعدی و زوایای دید:**
   - چرخش ۳۶۰ درجه، زوم، Pan با OrbitControls.
   - کلیدهای سریع نماهای استاندارد: ایزومتریک (3D)، نمای بالا (Top/2D)، نمای روبرو (Front)، نمای پهلو (Side).
   - انواع متریال مهندسی: فولاد، برنج، آلومینیوم، پلاستیک و مشبک (Wireframe).
   - خط‌کش و صفحه شطرنجی (Grid) به همراه محورهای مختصات XYZ.

5. **طراحی هوشمند، زیبا و دو زبانه:**
   - دو زبانه کامل: **فارسی (RTL)** و **انگلیسی (LTR)** با کلید تغییر سریع.
   - تم شب (Dark Mode) و تم روز (Light Mode).
   - بدون نیاز به سرور یا نصب نرم‌افزار جانبی؛ با دو بار کلیک روی `index.html` اجرا می‌شود.

---

## 🚀 نحوه اجرا (How to Run)

کافیست فایل `index.html` را در هر مرورگری (Chrome, Edge, Firefox) باز کنید.
همچنین می‌توانید پوشه را روی هاست‌های ابری رایگان مثل **GitHub Pages**، **Netlify** یا **Vercel** مستقر کنید.
